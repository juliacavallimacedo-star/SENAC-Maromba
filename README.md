# SENAC-Maromba

REALIZAÇÃO DA MATRÍCULA:
- menores de 16 anos não podem ter matricula.
- a partir de 16 anos e aos 17, precisa de autorização.
- a partir dos 18 anos é possivel realizar a matricula de forma independente.

- buscar facilitar a realização da matricula pro cliente, não queremos que ele desista da academia.
  o cliente deve fazer a matrícula com o uso do e-mail e cpf.
  obrigatório o adiantamento de 3 meses de pagamento.

- comunicar que o cliente deve ter total comprometimento com a academia.
- as informações de idade desevem estar no inicio do documento antes dele preencher com os propros dados.


Requisitos do Sistema


Item	Descrição
01	O sistema deve solicitar a idade do cliente.

02	O sistema deve verificar se a idade informada é válida.

03	O sistema deve apresentar uma mensagem clara informando se a matrícula foi permitida ou negada.

04	Pessoas menores de 16 anos não podem realizar a matrícula.

05	Pessoas com 16 ou 17 anos precisam apresentar autorização do responsável para concluir a matrícula.

06	Pessoas com 18 anos ou mais podem realizar a matrícula normalmente.

07	O sistema deve ser desenvolvido obrigatoriamente na linguagem Python.

08	O sistema deve apresentar mensagens limpas, claras e de fácil compreensão.

09	O sistema deve executar a validação de forma rápida e instantânea.

10	O sistema deve possuir uma interface simples para o usuário (via terminal de comandos).

11	O campo de entrada de idade deve aceitar estritamente números inteiros.

12	O processo de matrícula deve ser ágil e simplificado para facilitar a adesão e evitar que o cliente desista da academia.

13	O sistema deve exigir e validar o e-mail e o CPF do cliente para a realização do cadastro.

14	O sistema deve aplicar a obrigatoriedade do pagamento adiantado equivalente a 3 meses contratados para a efetivação da matrícula.
